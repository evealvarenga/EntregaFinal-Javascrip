# 🍕 Sabores Argentinos - Proyecto web

Bienvenido/a al proyecto Entrega Final de JavaScript 🙌

Este repositorio contiene la entrega final del trabajo práctico desarrollado con HTML, CSS y JavaScript. El objetivo principal es poner en práctica los conocimientos aprendidos durante el curso/programación, implementando funcionalidades interactivas y diseño responsivo.

---

## Descripción

Este proyecto es una página web interactiva desarrollada como entrega final de un curso o práctica de JavaScript. Incluye:

Una estructura HTML organizada.

Estilos CSS personalizados para diseño visual.

Lógica en JavaScript para manejar interactividad o dinámicas en la página.

👉 El sitio está desplegado y podés verlo en:
🔗 entrega-final-javascrip-gray.vercel.app

---

## Estructura del proyecto

La organización del repositorio es la siguiente:
```
/
├── css/               # Estilos CSS
├── img/               # Imágenes usadas en la web
├── pages/             # Páginas internas del sitio
├── script/            # Archivos JavaScript
├── index.html         # Página principal
└── .gitattributes     # Configuración de atributos Git
```

---

## Tecnologías utilizadas

Este proyecto fue construido con:
- **HTML5** → Estructura de la página y contenidos.
- **CSS3** → Estilos y diseño visual.
- **JavaScript** → Lógica y funcionalidad dinámica.

---

## Objetivos del proyecto

- Aplicar conceptos básicos de maquetación web.  
- Crear una estructura semántica clara y ordenada.  
- Implementar estilos visuales modernos con CSS.  
- Representar la temática visual y narrativa de la película a través del diseño.
